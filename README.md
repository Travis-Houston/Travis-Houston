## Featured project

### [Terraform CI/CD Infrastructure Pipeline](https://github.com/Travis-Houston/Terraform-Github-Actions-Pipeline)

*Terraform · GitHub Actions · HCP Terraform · Checkov*

An Infrastructure-as-Code pipeline for AWS that automates Terraform formatting, validation, security scanning, pull-request plan generation, remote state management, and infrastructure deployment.

The pipeline also includes smart change detection, workspace auto-discovery, and parallel execution for affected environments.
